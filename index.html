Project Overview

"3D Racer: Insane Mode" is a project intended to bring the user a unique arcade highway racing experience by using two devices simultaneously. Developed using p5.js for the rendering engine and Node.js with Socket.io for the networking layer, this project allows users to utilize a mobile device as a dedicated controller. Our goal was to make a car game with a controller, since we took on that challenge there were several issues that we had to overcome. But at the end of the day, we had made a fully working highway racer with a phone as a controller.

Technical Instructions

  • Local Deployment: Initialize the Node.js server. The primary display acts as the game engine, while the /controller.html route serves the mobile UI.
  • Desktop Input: Standard movement is mapped to WASD and Arrow Keys.
  • Network Input: Mobile controller/html would connect to the internet and through socket.io reach the server, which the server would be online to store and provide information about steering.

Learning Goal: Methods with Parameters

This method is like a reusable method for our cars. Instead of writing out the long instructions for drawing a 3D car over and over again, we wrote them once and added a "slot" called bodyColor. This slot is the parameter. When we want a red car for the player, we put "red" into that slot. When we want a blue car for traffic, we put "blue" in.

Learning Goal: Return Values

Our project features a custom method called checkCollision(p, n) that acts for the game’s physics. This method takes two specific objects—the player and an NPC—and calculates the distance between their 3D coordinates. After performing the math, it returns a Boolean value: true if a collision is detected, or false if the path is clear. Why it was useful: By using a return value, we successfully separated the "math logic" from the "game action." This made our code much more organized; the main drawing loop doesn't need to understand the complex geometry of a hit-box, it only needs the "yes or no" answer provided by the return. This method allowed us to tweak the game to increase difficulty as the player accelerates.
